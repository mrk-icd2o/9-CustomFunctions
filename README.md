# Lab 9 - Custom Functions

You will be writing your code in `sketch.js` within the main folder - not the `example/` folder.


## Part 1

- Choose any multi-shape object you've created in a lab or assignment (or create a new one).

- Create a function that can draw that object at any x and y position you choose.

- Include another parameter that changes another part of the object (colour etc).

- Draw the object multiple times (call the function multiple times).

## Part 2

Add a **size** parameter to your function. Changing the size must keep everything **to scale**: every shape, and the distances between them, should grow and shrink together.

See [this example](https://openprocessing.org/sketch/2918011/embed/?plusEmbedHash=65725741&userID=175929&plusEmbedTitle=true&show=sketch).
